◆ LED_blink()

void LED_blink ( void * ptr)

sends data to peer using esp_now and blinks the LED if 30 seconds have passed since the last invalid scan.

After recieving the data from the queue this function sends a signal to a peer ESP32-S3 using esp_now if the data indicates an invalid scan. Additionally if 30 seconds have passed and the last scan was invalid the LED starts blinking only stopping once a new scan is read. if an invalid scan is proceeded by a valid scan this function will also send the updated data to the peer.

◆ valid_RFID_decider_and_checker()

void valid_RFID_decider_and_checker ( void * ptr)

Registers the first ID scan to occur as valid. All ID's that don't much this ID are considered invalid.

This task constantly scans for an ID card to scan. The found ID is locked as the valid ID for the rest of the time this program runs from there onwards it compares all future scans with the valid ID and sends the match through 2 queues one is sent to match_LCD_task the other is sent to LED_blink. This makes sure each check can be processed by both tasks regardless of outside interferences once a card is scanned rfid.halt() is called so that each card scan only accounts for one scan.
